# Фича: картинки на карточке слота

## Симптом / цель

На карточке слота (список прогулок, `SCR-002`) вместо фотографии рендерился
декоративный цветной градиент-заглушка. Нужно, чтобы каждая карточка слота
показывала реальную картинку прогулки.

Источник картинок — локальная папка `surfs_images_328x120/` в корне репозитория
(10 стоковых фото с Pexels, без лицензионных ограничений для демо).

Ни backend, ни OpenAPI-контракты, ни доменная модель `Slot`/`Route` не содержат
поля с URL картинки — это подтверждено анализом кода перед реализацией. Значит,
фича полностью клиентская: картинки собираются с приложением как ресурсы, а не
подгружаются по сети.

## Решение

- Мапинг картинка → карточка: **по `slot.id`** (стабильный хеш `id` по модулю
  количества картинок), а не по `route.id`. Так каждый конкретный слот всегда
  показывает одну и ту же картинку между перезагрузками экрана, а разные слоты
  одного маршрута в разное время могут показывать разные картинки — визуальное
  разнообразие в списке.
- Картинки подключены через Compose Multiplatform Resources
  (`client/shared/src/commonMain/composeResources/drawable/`), т.к. это
  KMP-приложение (Android/iOS/Web) и ресурсы должны быть доступны на всех
  платформах без отдельной сетевой загрузки.
- Файлы скопированы из `surfs_images_328x120/` и переименованы в
  `slot_photo_1.jpg` … `slot_photo_10.jpg` — Compose Resources не допускает
  дефисы в именах ресурсов (только `[a-z][a-z0-9_]*`), поэтому оригинальные
  имена вида `pexels-aperture-29438625.jpg` использовать напрямую нельзя.
- Изменённый код: `SlotPreviewPhoto` в
  `client/shared/src/commonMain/kotlin/com/volna/app/catalog/presentation/SlotListScreen.kt`
  — теперь рендерит `Image` с `painterResource`, `ContentScale.Crop`, поверх
  сохранён нижний градиент-оверлей для читаемости (был и раньше, для будущего
  текста поверх фото).
- В `client/shared/build.gradle.kts` добавлена зависимость
  `compose.components.resources` и настройка
  `compose.resources { packageOfResClass = "com.volna.app.resources" }`.

   > кроме того создай md файл где опиши симптом или цель, и все мои промпты
   > касательно этой фичи. если будут вопросы, задавай

2. Уточняющий вопрос от ассистента (мапинг картинки к карточке: по слоту или по
   маршруту) → ответ пользователя: **«По id слота»**.
